What this laboratory shows

FLEX burned single droplets of methanol and n-heptane in the Combustion Integrated Rack on the International Space Station. Without buoyant convection the flames are spherical, so droplet and flame sizes over time can be compared directly with one-dimensional theory. This laboratory presents the published results of the first FLEX tests, test by test, with the source of every value.

Share this run, or check someone else's

A run file holds the inputs, results, model and property-table versions and the printed-value comparison. It has no personal data and no timestamp. Anyone can re-run it here or with python3 -m openflex check-run. Reproduced means the documented model gives the same numbers from the same inputs; it does not mean the model agrees with FLEX, and nothing here is validation.

Condition coverage of Table IX ("domain status")

COVERAGE OF TESTED CONDITIONS — NOT A VALIDATION DOMAIN

How close are these conditions to conditions that were actually tested? Compared within the same fuel and diluent class (He if He > 0, else CO₂ if CO₂ > 0, else N₂), using printed Table IX values of pressure, O₂ and D₀. "Near" means a normalized distance ≤ 0.25 to at least one test (a declared convention, not a statistic). No model in this build is validated anywhere.
